เครื่องมือครู สำหรับ macOS และ Windows

GradeCheck

เทียบไฟล์ PDF ที่ออกจากระบบ SGS กับไฟล์ Excel ของคุณ แล้วชี้ให้เห็นทุกช่องที่ไม่ตรงกัน

macOS และ Windows ทดลองฟรี 3 ห้องเรียน 49 บาท จ่ายครั้งเดียว

ดาวน์โหลดสำหรับ macOS ดาวน์โหลดสำหรับ Windows

macOS ได้ไฟล์ .dmg · Windows ได้ไฟล์ .zip ทั้งสองระบบจะขึ้นคำเตือนตอนเปิดครั้งแรก อ่านหัวข้อติดตั้งด้านล่าง

ปัญหาที่โปรแกรมนี้แก้

คะแนนที่คีย์เข้าระบบ SGS อาจมีจุดผิดพลาดที่มองไม่เห็นด้วยตาเปล่า เช่น เลขสลับตำแหน่ง ช่องคะแนนที่ยังไม่ได้กรอก หรือยอดรวมที่ไม่ได้คำนวณใหม่หลังแก้ไขคะแนนย่อย ความผิดพลาดเหล่านี้บางครั้งหักล้างกันจนยอดรวมดูเหมือนถูกต้อง ทั้งที่จริงแล้วไม่ใช่

GradeCheck อ่านทั้งสองไฟล์แล้วเทียบให้ทีละช่อง โดยถือว่า ไฟล์ Excel ของคุณคือข้อมูลที่ถูกต้อง

โปรแกรมนี้ทำอะไร

  • จับคู่ด้วยรหัสนักเรียน ไม่ใช่ชื่อ เพราะชื่อในไฟล์ PDF อาจเพี้ยนหรือหายไป
  • เทียบทีละช่อง ไม่ใช่แค่ยอดรวม คะแนนย่อยที่ผิดสองช่องอาจหักล้างกันจนยอดรวมตรง
  • บอกนักเรียนที่ขาดหรือเกิน คนที่อยู่ในไฟล์หนึ่งแต่ไม่อยู่ในอีกไฟล์
  • ปรับผังคอลัมน์ได้เอง ผ่านเมนู Manage Profiles ไม่ต้องแก้โค้ด เพราะแต่ละวิชาและแต่ละเทอมวางคอลัมน์ไม่เหมือนกัน
  • ส่งออกผลเป็น CSV เก็บไว้เป็นหลักฐานหรือส่งต่อได้

ติดตั้งบน macOS

  1. เปิดไฟล์ .dmg แล้วลากไปที่ Applications

    ดับเบิลคลิกไฟล์ที่ดาวน์โหลดมา แล้วลาก GradeCheck ไปไว้ในโฟลเดอร์ Applications

  2. เปิดครั้งแรก

    แอปไม่ได้เซ็นด้วยบัญชี Apple Developer แบบเสียเงิน macOS จึงเตือนว่ามาจาก “นักพัฒนาที่ไม่ระบุตัวตน” ทำครั้งเดียวพอ

    macOS 13–14: คลิกขวาที่ไอคอนแอป เลือก Open แล้วกด Open อีกครั้งในกล่องข้อความ

    macOS 15 (Sequoia) ขึ้นไป: ดับเบิลคลิกหนึ่งครั้ง จะโดนบล็อก จากนั้นเปิด System Settings → Privacy & Security เลื่อนลงไปจนเห็นข้อความเกี่ยวกับ GradeCheck กด Open Anyway

ติดตั้งบน Windows

  1. แตกไฟล์ zip ทั้งหมดไว้ด้วยกัน

    คลิกขวาที่ไฟล์ที่ดาวน์โหลดมา เลือก Extract All แล้วแตกลงในโฟลเดอร์ที่ต้องการเก็บโปรแกรมไว้ถาวร เช่น ในโฟลเดอร์ Documents

  2. เปิด GradeCheck.exe จากในโฟลเดอร์นั้น

    Windows จะขึ้นหน้าจอสีน้ำเงิน SmartScreen ว่า “Windows protected your PC” ให้กด More info แล้วกด Run anyway ทำครั้งเดียวพอ

อย่าย้ายไฟล์ GradeCheck.exe ออกจากโฟลเดอร์ โปรแกรมต้องใช้ไฟล์อื่นที่อยู่ในโฟลเดอร์เดียวกันจึงจะเปิดได้ ถ้าต้องการเปิดง่าย ๆ ให้คลิกขวาที่ไฟล์ .exe แล้วเลือก Show more options → Send to → Desktop เพื่อสร้างทางลัดแทน

วิธีใช้

  1. เตรียมไฟล์สองไฟล์

    ไฟล์ PDF ที่ออกจากระบบ SGS และไฟล์ Excel ของคุณเองสำหรับวิชาและเทอมเดียวกัน

  2. เลือกโปรไฟล์ให้ตรงกับผังคอลัมน์

    โปรไฟล์คือการจดจำว่าคอลัมน์ไหนในไฟล์ PDF และไฟล์ Excel เก็บคะแนนช่องใด และชีตไหนตรงกับห้องไหน ตั้งค่าได้จากเมนู Manage Profiles ไม่ต้องแก้ไฟล์ JSON เอง

  3. สั่งเปรียบเทียบ

    โปรแกรมจะแสดงทุกช่องที่ไม่ตรงกัน พร้อมบอกว่าในไฟล์ Excel เป็นเท่าไร และในไฟล์ PDF เป็นเท่าไร รวมถึงนักเรียนที่ขาดหรือเกิน

  4. แก้ไขในระบบ SGS แล้วออกไฟล์ PDF ใหม่มาตรวจซ้ำ

    ทำซ้ำจนกว่าจะไม่พบจุดที่ไม่ตรงกัน

ราคาและการทดลองใช้

ทดลองใช้ได้ฟรี 3 ห้องเรียนแรก ต่อหนึ่งเครื่อง นับรวมตลอดไป ไม่ใช่ต่อไฟล์และไม่ใช่ต่อการเปิดใช้แต่ละครั้ง ปลดล็อกให้ใช้ได้ไม่จำกัดจำนวนห้องเรียนด้วยไลเซนส์แบบ จ่ายครั้งเดียว 49 บาท

การเปิดไฟล์ชุดเดิมซ้ำจะเห็นห้องเรียนเดิมได้ฟรีเสมอ ไม่นับเพิ่ม มีเพียงห้องเรียนที่ไม่เคยเห็นมาก่อนเท่านั้นที่นับจากโควตา ถ้าเปิดไฟล์ที่มีห้องเรียนใหม่เกิน 3 ห้องตั้งแต่ครั้งแรก โปรแกรมจะเทียบให้ 3 ห้องแรกตามปกติ พร้อมบอกว่ายังมีอีกกี่ห้องที่ยังไม่ได้แสดง

ห้องเรียนถูกระบุจากเนื้อหาของไฟล์ ไม่ใช่จากรายชื่อนักเรียน ถ้าเทอมหน้าไฟล์ของห้องเดิมมีข้อมูลต่างไปแม้เพียงเล็กน้อย จะนับเป็นห้องเรียนใหม่และดึงจากโควตาอีกครั้ง
