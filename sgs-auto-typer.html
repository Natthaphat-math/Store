เครื่องมือครู สำหรับ macOS

SGS Auto-Typer

พิมพ์คะแนนจาก Excel, Google ชีต หรือคลิปบอร์ด ลงหน้ากรอกคะแนนของ SGS ให้อัตโนมัติ

macOS 13 (Ventura) ขึ้นไป Apple silicon และ Intel ฟรี

ดาวน์โหลดสำหรับ macOS หน้าทดสอบสำหรับซ้อม

ไฟล์ .zip · หลังแตกไฟล์แล้วยังต้องตั้งค่าอีก 2 ขั้นตอนก่อนใช้งานครั้งแรก อ่านหัวข้อติดตั้งด้านล่าง

โปรแกรมนี้ทำอะไร

แทนที่จะพิมพ์คะแนนทีละคนลงหน้าเว็บ SGS โปรแกรมจะอ่านคะแนนจากไฟล์ของคุณ แล้วพิมพ์ลงช่องให้เอง โดยจำลองการกดแป้นพิมพ์จริง จึงใช้กับหน้าเว็บ SGS ได้ตามปกติ ไม่ต้องติดตั้งส่วนเสริมในเบราว์เซอร์

  • รับคะแนนจากไฟล์ .xlsx, .csv, .tsv หรือคัดลอกเซลล์มาวางตรง ๆ
  • เดาคอลัมน์ให้เองจากหัวตารางภาษาไทย เช่น เลขที่ กลางภาค ปลายภาค
  • เลือกได้ว่าจะพิมพ์แถวไหนบ้าง และเรียงลำดับใหม่ได้ก่อนเริ่ม
  • หยุดกลางคันได้ทันทีหลายวิธี
  • ทำงานในเครื่องทั้งหมด ไม่ต่ออินเทอร์เน็ต

โปรแกรมนี้เป็นตัวช่วยพิมพ์แทนคุณเท่านั้น ใช้กับคะแนนของห้องที่คุณรับผิดชอบ และมีสิทธิ์กรอกอยู่แล้ว การตัดสินว่าคะแนนถูกต้องหรือไม่ยังเป็นของคุณ ตรวจทานคะแนนบนหน้า SGS ทุกครั้งก่อนกดบันทึก

ติดตั้ง

  1. ดาวน์โหลดและย้ายไปที่ Applications

    แตกไฟล์ zip ที่ดาวน์โหลดมา แล้วลาก SGS Auto-Typer.app ไปไว้ในโฟลเดอร์ Applications

  2. เปิดครั้งแรก

    แอปนี้ไม่ได้เซ็นด้วยบัญชี Apple Developer แบบเสียเงิน ครั้งแรกที่เปิด macOS จะเตือนว่ามาจาก “นักพัฒนาที่ไม่ระบุตัวตน” ซึ่งเป็นเรื่องปกติ ทำครั้งเดียวพอ ครั้งต่อไปเปิดได้ตามปกติ

    macOS 13–14: คลิกขวาที่ไอคอนแอป เลือก Open แล้วกด Open อีกครั้งในกล่องข้อความ

    macOS 15 (Sequoia) ขึ้นไป: ดับเบิลคลิกแอปหนึ่งครั้ง จะโดนบล็อก จากนั้นเปิด System Settings → Privacy & Security เลื่อนลงไปจนเห็นข้อความเกี่ยวกับ SGS Auto-Typer กด Open Anyway แล้วยืนยันด้วยรหัสผ่านหรือ Touch ID

  3. เปิดสิทธิ์ Accessibility

    โปรแกรมต้องได้รับสิทธิ์นี้จึงจะพิมพ์แทนคุณลงในเบราว์เซอร์ได้ วิธีที่ง่ายที่สุดคือให้แอปพาไปเอง เปิดแอป กดปุ่ม ? มุมขวาบน แล้วในขั้นตอนที่ 1 กด ขอสิทธิ์และเปิดการตั้งค่า macOS จะเปิดหน้าที่ถูกต้องให้พร้อมเพิ่มชื่อแอปในรายการ จากนั้นเปิดสวิตช์ข้างชื่อแอปให้เป็นสีเขียว

    ถ้ายังไม่ทำงาน ให้ปิดแอปแล้วเปิดใหม่อีกครั้ง

หาหัวข้อ Accessibility ในรายการไม่เจอ? บน macOS รุ่นใหม่ Apple เปลี่ยนชื่อรายการนี้เป็น Device Control and Data Access จึงไม่มีคำว่า Accessibility ให้เห็น

วิธีที่ได้ผลทุกรุ่น: พิมพ์ accessibility ในช่องค้นหามุมซ้ายบนของ System Settings แล้วเลือกผลลัพธ์ “Allow assistive applications to control the computer” ที่มีคำว่า Privacy & Security อยู่ใต้ชื่อ จากนั้นเลื่อนหา SGS Auto-Typer.app แล้วเปิดสวิตช์ ถ้าไม่มีชื่อแอปในรายการ กดปุ่ม + มุมล่างซ้าย แล้วเลือกแอปจากโฟลเดอร์ Applications

ระวังสับสน: Accessibility ที่เป็นหมวดตั้งค่าใหญ่ (VoiceOver, ซูม, ขนาดตัวอักษร) เป็นคนละอันกับรายการให้สิทธิ์แอปควบคุมเครื่อง อันที่ต้องใช้คืออันหลัง

ทุกครั้งที่ดาวน์โหลดแอปเวอร์ชันใหม่ macOS อาจถือว่าเป็นแอปคนละตัว และต้องเปิดสวิตช์นี้ใหม่อีกครั้ง

วิธีใช้

  1. ซ้อมกับหน้าทดสอบก่อน

    ในแอปกดปุ่ม ? มุมขวาบน แล้วกด เปิดหน้าทดสอบเพื่อซ้อม ลองให้แอปพิมพ์ลงหน้านั้นก่อน อย่าเพิ่งใช้กับคะแนนจริง

  2. เปิดหน้ากรอกคะแนนของ SGS

    เข้าสู่ระบบ SGS ด้วยตัวเอง แล้วเปิดหน้ากรอกคะแนนของห้องที่ต้องการ ตรวจว่าลำดับนักเรียนบนหน้าเว็บตรงกับลำดับในไฟล์ของคุณ

  3. นำคะแนนเข้าโปรแกรม

    คัดลอก–วาง เลือกช่วงเซลล์คะแนนใน Excel หรือ Google ชีต กด ⌘C แล้วสลับมาที่แอป กดปุ่ม วางจากคลิปบอร์ด จะคัดลอกมาคอลัมน์เดียวหรือหลายคอลัมน์ก็ได้ ไม่ต้องมีหัวตาราง

    หรือเปิดไฟล์ ลากไฟล์ .xlsx หรือ .csv เข้าไป หรือกดปุ่มเลือกไฟล์

  4. ตรวจตารางตัวอย่างและเลือกคอลัมน์

    ติ๊กเลือกหรือไม่เลือกแถวได้ เลื่อนลำดับแถวได้ จากนั้นเลือกคอลัมน์คะแนนที่จะพิมพ์ให้เรียงตามลำดับช่องบนหน้า SGS

  5. กดเริ่มพิมพ์

    กด เริ่มพิมพ์ แล้วรีบสลับไปที่เบราว์เซอร์ และคลิกในช่องคะแนนช่องแรก ก่อนหมดเวลานับถอยหลัง (ค่าเริ่มต้น 5 วินาที ปรับได้) แถบลอยด้านบนจอจะบอกว่ากำลังพิมพ์คะแนนของใคร

  6. ตรวจทานก่อนบันทึก

    เมื่อพิมพ์เสร็จ ตรวจทานคะแนนบนหน้า SGS ให้เรียบร้อยก่อนกดบันทึกเสมอ

หยุดฉุกเฉิน

ระหว่างที่โปรแกรมกำลังพิมพ์ หยุดได้ทันทีด้วยวิธีใดก็ได้ต่อไปนี้

  • กดปุ่ม Esc
  • เลื่อนเมาส์ไปที่มุมจอ มุมใดก็ได้
  • กดปุ่ม หยุด บนแถบลอย
  • สลับไปโปรแกรมอื่น ถ้าเปิดตัวเลือกนี้ไว้ แอปจะหยุดเองเพื่อความปลอดภัย

ไฟล์ที่รองรับ

  • .xlsx อ่านได้โดยตรง รองรับหลายชีต
  • .csv รวมถึงไฟล์ที่ส่งออกจาก Google ชีต (UTF-8 หรือ Windows-874/TIS-620)
  • .tsv ข้อมูลที่คัดลอกจาก Google ชีตแล้ววางในไฟล์ข้อความ
  • คลิปบอร์ด คัดลอกช่วงเซลล์มาวางตรง ๆ ไม่ต้องบันทึกเป็นไฟล์

ไฟล์ .xls รุ่นเก่ายังไม่รองรับ เปิดใน Excel แล้วบันทึกใหม่เป็น .xlsx หรือ .csv

การตั้งค่าที่ปรับได้

การตั้งค่าค่าเริ่มต้นปรับเมื่อไร
หน่วงเวลาต่อตัวอักษร120 ms เพิ่มถ้าตัวเลขตกหล่นหรือหน้าเว็บช้า
หน่วงเวลาระหว่างช่อง200 ms เพิ่มถ้าหน้าเว็บใช้เวลาโหลดช่องถัดไป
ปุ่มเลื่อนช่องTab เปลี่ยนเป็น Enter ถ้าหน้า SGS ใช้ Enter
เลือกข้อความเดิมก่อนพิมพ์เปิด ทำให้คะแนนเดิมถูกแทนที่ ไม่ใช่ต่อท้าย
ลำดับการพิมพ์ทีละนักเรียน เปลี่ยนเป็นทีละคอลัมน์ ถ้าหน้าเว็บวิ่งลงคอลัมน์
นับถอยหลัง5 วินาที เพิ่มถ้าสลับหน้าต่างไม่ทัน

สลับภาษาไทย/อังกฤษได้จากปุ่ม TH / EN มุมขวาบน และจะถูกจำไว้ให้ครั้งต่อไป

ปัญหาที่พบบ่อย

กดเริ่มแล้วไม่มีอะไรเกิดขึ้น
ยังไม่ได้เปิดสิทธิ์ Accessibility หรือเพิ่งเปิดแต่ยังไม่ได้ปิด-เปิดแอปใหม่ ดูขั้นตอนที่ 3 ของหัวข้อติดตั้ง
คะแนนตกหล่นบางตัว
หน้าเว็บช้ากว่าที่พิมพ์ ให้เพิ่มหน่วงเวลาต่อตัวอักษรเป็น 180–250 ms และหน่วงเวลาระหว่างช่องเป็น 300–400 ms แล้วลองใหม่กับหน้าทดสอบ
คะแนนไปลงผิดช่อง
ลำดับนักเรียนในไฟล์ไม่ตรงกับหน้า SGS กด Esc ทันที แล้วเรียงลำดับแถวในตารางตัวอย่างให้ตรงกันก่อน
คะแนนถูกพิมพ์ต่อท้ายของเดิม
เปิดตัวเลือก “เลือกข้อความเดิมในช่องก่อนพิมพ์ทับ”
โปรแกรมพิมพ์ลงในหน้าต่างของแอปเอง
แอปจะไม่เริ่มพิมพ์ถ้ายังไม่ได้สลับไปเบราว์เซอร์ และจะขึ้นข้อความเตือนแทน
